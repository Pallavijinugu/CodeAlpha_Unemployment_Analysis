# CodeAlpha - Unemployment Analysis with Python

## Project Overview
This project analyzes unemployment rate data in India using Python. The analysis focuses on unemployment trends, Covid-19 impact, state-wise unemployment rates, and seasonal patterns using data visualization and exploratory data analysis techniques.

This project was completed as part of the CodeAlpha Data Science Internship.

---

## Objectives
- Analyze unemployment rate data.
- Perform data cleaning and preprocessing.
- Explore unemployment trends using visualizations.
- Study the impact of Covid-19 on employment.
- Identify seasonal and regional unemployment patterns.
- Generate insights useful for economic and social policy decisions.

---

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## Dataset
Dataset: Unemployment in India Dataset

File Used:
`Unemployment_Rate_upto_11_2020.csv`

## Steps Performed

### 1. Data Collection
- Downloaded unemployment dataset from Kaggle.

### 2. Data Cleaning
- Removed missing values.
- Renamed columns.
- Converted date columns into datetime format.

### 3. Exploratory Data Analysis
- Checked dataset structure.
- Generated descriptive statistics.
- Analyzed unemployment trends.

### 4. Data Visualization
Created different visualizations using Matplotlib and Seaborn:
- Line plots
- Bar charts
- Heatmaps

### 5. Covid-19 Analysis
- Compared unemployment rates before and during Covid-19.
- Observed increase in unemployment during lockdown period.

---

## Key Insights
- Unemployment increased significantly during the Covid-19 pandemic.
- Some states showed consistently high unemployment rates.
- Monthly unemployment trends indicate seasonal variation.
- Labour participation rate has correlation with unemployment.
- Covid-19 strongly affected employment opportunities.
